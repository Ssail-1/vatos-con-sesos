# Próximas features

Esta carpeta contiene ideas, posibles cambios, bugs observados y
funcionalidades consideradas para entregas futuras.

Su contenido sirve únicamente como referencia para el desarrollador.

Los archivos de esta carpeta:

- no son instrucciones vigentes para Codex;
- no deben implementarse automáticamente;
- pueden contener ideas incompletas;
- pueden cambiar o descartarse;
- no deben ampliar el alcance de la tarea actual.

Codex solo debe implementar una idea de esta carpeta cuando haya sido
incorporada explícitamente a los documentos normativos de una entrega.
