# Tarea actual

## Nombre

Frontend MVP 01 — Matriz mensual responsive con foco en el día actual.

## Objetivo

Construir exclusivamente el primer prototipo frontend del módulo:

`modules/gestor_de_habitos/`

El propósito de esta entrega es validar la estructura visual,
la representación mensual de actividades y el control multestado.

## Alcance técnico

Usar únicamente:

- HTML
- CSS
- JavaScript nativo
- datos simulados en memoria

No utilizar:

- Flask
- PostgreSQL
- Supabase
- API
- localStorage
- autenticación
- frameworks frontend
- librerías externas

## Archivos autorizados

Codex puede crear o modificar únicamente archivos dentro de:

`modules/gestor_de_habitos/`

No debe modificar ningún archivo exterior.

## Resultado esperado

La entrega debe mostrar:

- el mes actual;
- una lista de actividades simuladas;
- información temporal resumida;
- todos los días del mes en escritorio amplio;
- solamente el día seleccionado en pantallas estrechas;
- un control multestado para cada aparición diaria;
- diseño oscuro y responsive.

## Fuera de esta entrega

No implementar todavía:

- creación de actividades;
- botón contextual para insertar filas;
- seguimiento temporal expandido;
- modales;
- comentarios;
- subactividades;
- recurrencias;
- persistencia;
- cálculo de estadísticas;
- porcentajes;
- rachas;
- reajuste automático de horarios;
- backend.

## Forma de trabajo

Antes de implementar, Codex debe:

1. Leer todos los documentos normativos de `/docs/codex/`.
2. Inspeccionar `modules/gestor_de_habitos/`.
3. Indicar los archivos que creará o modificará.
4. Resumir el comportamiento responsive que implementará.

Después puede construir esta entrega sin ampliar el alcance.
