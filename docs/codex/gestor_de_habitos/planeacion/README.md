# Documentos de planeación

Los archivos de esta carpeta conservan la historia, las ideas,
preguntas y decisiones consideradas durante el diseño del módulo.

Su contenido sirve exclusivamente como contexto.

Estos documentos:

- no constituyen instrucciones definitivas;
- pueden contener ideas descartadas;
- pueden contener contradicciones;
- pueden describir funciones futuras;
- no deben utilizarse para ampliar automáticamente el alcance actual.

La fuente de verdad para la implementación está en:

1. `/AGENTS.md`
2. `/docs/codex/CURRENT_TASK.md`
3. `/docs/codex/FRONTEND_MVP_01.md`
4. `/docs/codex/UI_REFERENCE.md`
5. `/docs/codex/MOCK_DATA_CONTRACT.md`
6. `/docs/codex/ACCEPTANCE_CRITERIA_MVP_01.md`

En caso de contradicción, los documentos anteriores tienen prioridad
sobre cualquier archivo de esta carpeta.
