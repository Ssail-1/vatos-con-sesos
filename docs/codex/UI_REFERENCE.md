# Referencia visual

## Imagen principal

`assets/Ejemplo-objetivo-plantilla.png`

Esta imagen representa la intención de la vista amplia:

- lista vertical de actividades;
- información temporal a la izquierda;
- días del mes distribuidos horizontalmente;
- un estado por actividad y día;
- fuerte jerarquía del mes;
- diseño compacto y de lectura rápida.

No deben implementarse en esta entrega:

- estadísticas;
- rachas;
- porcentajes;
- notas;
- progreso mensual;
- fórmulas de Google Sheets.

## Referencia de seguimiento temporal resumido

`assets/Seguimiento temporal resumido sin cambios registrados.png`

Para la primera entrega solo se toma de esta referencia:

- hora de inicio;
- duración estimada;
- nombre de la actividad;
- distribución compacta de cada fila.

El control para expandir el seguimiento temporal se implementará después.

## Referencia de seguimiento temporal expandido

`assets/Seguimiento temporal collapsado con cambios registrados.png`

Esta imagen solamente proporciona contexto para una entrega futura.

No construir todavía:

- expansión temporal;
- hora final visible;
- tiempo real;
- modal de modificación.

## Tema visual

La interfaz debe:

- utilizar un fondo oscuro;
- mantener coherencia con Vatos con Sesos;
- utilizar dorado o amarillo como acento;
- tener texto legible;
- utilizar filas compactas;
- diferenciar claramente encabezados, actividades y estados.

La apariencia debe inspirarse en las imágenes, pero adaptarse correctamente
a una aplicación web responsive.
