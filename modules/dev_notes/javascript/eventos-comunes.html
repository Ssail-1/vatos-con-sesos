Eventos comunes

Evento Descripción
onchange Se ejecuta cuando cambia el valor de un elemento.
onclick Se ejecuta cuando el usuario hace clic sobre un elemento.
onmouseover Se ejecuta cuando el cursor entra en un elemento.
onmouseout Se ejecuta cuando el cursor sale de un elemento.
onkeydown Se ejecuta cuando el usuario presiona una tecla.
onload Se ejecuta cuando la página termina de cargarse.
