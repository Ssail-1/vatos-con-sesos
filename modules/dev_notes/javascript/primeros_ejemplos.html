JavaScript

Introducción

  • Con JavaScript agregamos comportamiento e interactividad a una página web.
  • HTML define la estructura.
  • Y CSS controla su apariencia.

Estos primeros experimentos sirven como una vista previa: veremos cómo JavaScript puede seleccionar elementos HTML y modificar su contenido, sus atributos y sus estilos.

Primeros ejemplos

Cambiar contenido HTML

Este texto cambiará al presionar el botón.

Para realizar el cambio se utiliza el método getElementById(), que permite seleccionar un elemento HTML mediante el valor de su atributo id.

Ver código del ejemplo 

<p id="cambio-de-texto">
    Este texto cambiará al presionar el botón.
</p>

<button
    type="button"
    onclick='document.getElementById("cambio-de-texto").textContent = "El texto ya cambió."'
>
    Cambiar texto
</button>

<button
    type="button"
    onclick='document.getElementById("cambio-de-texto").textContent = "Este texto cambiará al presionar el botón."'
>
    Restaurar texto
</button>

Se utiliza textContent porque solo queremos modificar texto. innerHTML también puede insertar etiquetas HTML, pero no es necesario en este ejemplo.

Cambiar atributos de un elemento

En este ejemplo se modifica el valor del atributo src de una imagen para encender o apagar un foco.

Ver código del ejemplo 

<button
    type="button"
    onclick="document.getElementById('foco').src = './assets/images/pic_bulbon.gif'"
>
    Encender
</button>

<img
    id="foco"
    src="./assets/images/pic_bulboff.gif"
    alt="Foco interactivo"
/>

<button
    type="button"
    onclick="document.getElementById('foco').src = './assets/images/pic_bulboff.gif'"
>
    Apagar
</button>

Cambiar estilos CSS

JavaScript también puede modificar los estilos de un elemento. En este caso cambiaremos el valor de la propiedad font-size.

Texto con tamaño predeterminado de 1em.

Ver código del ejemplo 

<p id="aumento-de-texto">
    Texto con tamaño predeterminado de 1em.
</p>

<button
    type="button"
    onclick="document.getElementById('aumento-de-texto').style.fontSize = '2em'"
>
    Aumentar texto
</button>

<button
    type="button"
    onclick="document.getElementById('aumento-de-texto').style.fontSize = '1em'"
>
    Restaurar tamaño
</button>

En fin...

JavaScript puede seleccionar un nodo del DOM y modificar su contenido, sus atributos o sus estilos.

Estos ejemplos utilizan JavaScript inline únicamente para observar el resultado de forma inmediata. Conforme avance el curso, el comportamiento se moverá a archivos JavaScript externos para separar la estructura de la lógica.
