Etiquetas semánticas

Practica por mi uni Hybridge Education

Las etiquetas semánticas describen el propósito del contenido, haciendo que el HTML sea más legible tanto para los desarrolladores como para los navegadores.

<main>

  • Representa el contenido principal de la página.
  • Solo debe existir un <main> por documento.

<section>

  • Agrupa contenido relacionado bajo un mismo tema.
  • Normalmente contiene un encabezado (<h2>, <h3>, etc.).

<article>

Representa contenido independiente que podría existir por sí solo, como una noticia, una publicación de blog o un comentario.

<header>

Define el encabezado de una página o de una sección. Puede contener el título, el logotipo o un menú de navegación.


    <header>
        <h1>Dev notes</h1>
        <nav>
            <a href="#inicio">Inicio</a>
            <a href="#nosotros">nosotros</a>
            <a href="#contactanos">contactanos</a>
        </nav>
    </header>

<footer>

Representa el pie de una página o de una sección. Generalmente contiene información de contacto, derechos de autor o enlaces adicionales.


<footer>

    <p>
        © 2026 Dev Notes
    </p>

</footer>

<nav>

Agrupa enlaces cuya función es permitir la navegación dentro del sitio.


    <nav>
        <ul>
            <li><a href="#inicio">Inicio</a></li>
            <li><a href="#nosotros">nosotros</a></li>
            <li><a href="#contactanos">contactanos</a></li>
        <ul>
    </nav>

<aside>

Representa contenido complementario al tema principal.

Piensa en un "¿Sabías que...?", una nota, una curiosidad o una barra lateral. No es el tema principal, pero ayuda al lector. O las alertas de GitHub como Note, Tip, Important, Warning y Caution.

Son información adicional, ayudan a digerir el contenido pero no forman parte del flujo principal del documento, si las quitaramos el contenido seguiría entendiendose pero ayudan mucho.

Esa es la filosofia de <aside> 

<aside>

    <h3>¿Sabías que...?</h3>

    <p>
        El DOM se representa como un árbol.
    </p>

</aside>

<figure> y <figcaption>

<figure> agrupa contenido independiente relacionado con el tema principal, como imágenes, diagramas, capturas de pantalla o gráficos.

<figcaption> agrega una descripción o pie para ese contenido.


<figure>

    <img src="dom.png"
         alt="Árbol DOM">

    <figcaption>

        Representación del árbol DOM.

    </figcaption>

</figure>
Una imagen dentro de un artículo puede entenderse sin el texto, pero el <figcaption> ayuda al lector a comprender exactamente qué representa.
