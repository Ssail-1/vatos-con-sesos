Atributos

Los atributos proporcionan información sobre las etiquetas en la apertura.

Van en pares nombre = "valor". Ejemplo:

  • <a href="https://www.ejemplo.com">Visita ejemplo</a>

En este caso href es el atributo y "https://www.ejemplo.com" es el valor.

Atributos para enlaces

A un lugar dentro de la pagina

Hacemos referencia hacia un id declarado en alguna etiqueta.
Por ejemplo, referenciaremos a un h2 a continuación. 


        < a href = "#nombre_de_id">Proceso de compra </a>
        <h2 id="nombre_de_id">"Politica de proceso de compra"</h2>

href

Especifica la URL del enlace:
<a href="https://www.ejemplo.com"></a>

target

target Es el atributo y especifica donde se abrira un documento vinculado.
Los valores determinan como se redirigue el usuario al vinculo:

  • _blank: Se abre en una nueva pestaña
  • _self: Se abre en la misma pesataña y es el valor predeterminado.

Buenas prácticas de seguridad para enlaces

La interacción con paginas externas deben ser protegidas y supervisadas

Es una buena practica usar target="_blank" para redirigir de manera segura al usuario cuando colocamos vinculos a paginas de terceros.

Restringe el acceso a windows.opener al abrir un enlace en nuestra página, evitando que no redirija nuestra pagina actual a una pagina maliciosa

rel="noopener"

Se restringe el acceso a nuestro windows.opener

rel="noreferer"

Con ello evitamos que la página a la que se enlazo no sepa de que página proviene y tampoco tiene acceso al windows.opener

rel="nofollow"

Le indica al motor que no indexee esa pagina, de esta manera de deslinda el propietario de la web de que ese enlace no le robe posicionamiento a la pagina actual.

Atributos para imagenes

src

Especifica la ruta de la imagen

<img src="ruta_de_la_imagen" alt="descripcion de la imagen">

alt

Si la imatgen no se puede cargar proporciona un texto alternativo para la imagen.

width y height

Especifica el ancho y alto de la imagen

<img src="imagen.jpg" alt="Descripción de la Imagen" width="300" height="200">

Atributos globales

Estos atributos se usan en conjunto con CSS y JavaScript.

id

Define un identificador único para un elemento HTML.
Ejemplo: 


            <id="introduccion">Este es un párrafo con un ID único.</p> 

            <img src="mi_imagen.jpeg" id="imagen_perfil" alt="user avatar" />

Este atributo es muy util para aplicar estilos CSS a elementos especificos o bien seleccionarlo con JavaScript para hacer alguna operación con el elemento.

class

Al crear una clase esta la podemos usar en diferentes elementos que representen una caracteristica compartida.
Por ejemplo: 


            <p class="texto-importante">
                Este es un párrafo.
            </p>

            <span class="texto-importante">
                Esto también es importante.
            </span>

            <li class="texto-importante">
                Este elemento también.
            </li>

Y cuando sea necesario podemos seleccionar los elemtos con esta clase y todos ellos van a modificarse.


            .texto-importante{
                color:red;
                font-weight:bold;
            }

Entonces todos los elementos estaran en rojo.

style

Permite aplicar estilos CSS directamente al elemento

<p style="color: red;">Este párrafo es de color rojo.</p>

A esto se le llama "estilos inline".
