Que calajos con index.html?

Historicamente es el archivo principal, imaginemos que tenemos el siguiente servidor. 

        📁 sitio-web

            📄 index.html
            📄 contacto.html
            📄 acerca.html

        📁 css
            📁 js
            📁 images

Y ahora, si alguien entra al sitio https://misitio.com/ no puso ningun archivo, entonces la ruta esta apuntando unicamente a la carpeta 📁 sitio-web.

Entonces, ¿Qué archivo abre el servidor?

Pues es aquí donde Los servidores adoptaron una convención.

Si el usuario solicita únicamente una carpeta, el servidor intentará abrir automaticamente un archivo llamado index.html
Entonces al ingresar a una ruta sin apuntar a un archivo, el servidor realmente intenta encontrar https://misitio.com/index.html, si existe lo devuelve, si no generalmente aparece un error.

Lo mismo ocurre dentro de cualquier carpeta y cualquier carpeta debería tener su propio index.html
