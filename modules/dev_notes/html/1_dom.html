🌳 DOM (Document Object Model)

Antes de entender qué es el DOM, es importante saber que los navegadores no trabajan directamente con el archivo HTML.

Supongamos que tenemos el siguiente documento:


<html>
    <body>
        <h1>Hola Yo</h1>

        <p>Aprendiendo desarrollo web</p>

        <button>Saludar</button>
    </body>
</html>

Cuando el navegador abre este archivo, no manipula el HTML como texto.

En su lugar, interpreta el documento y construye una representación interna de toda la página con una estructura jerárquica.

Visualmente sería algo parecido a esto:


Documento
│
└── html
      │
      └── body
             │
             ├── h1
             │      └── "Hola Yo"
             │
             ├── p
             │      └── "Aprendiendo desarrollo web"
             │
             └── button
                    └── "Saludar"

Podemos observar que esta representación tiene forma de un árbol, donde cada elemento HTML se convierte en un nodo.

🌳 Ese árbol se llama DOM

DOM significa:

Document Object Model

Modelo de Objetos del Documento

Es la representación que el navegador crea del documento HTML para poder comprender la página y permitir que JavaScript interactúe con ella.

¿Por qué se llama "Modelo"?

Porque no es el archivo HTML, sino una representación del mismo.

El navegador crea este modelo en memoria para poder trabajar con la página de forma rápida y eficiente.

¿Por qué "Objeto"?

Porque cada etiqueta HTML deja de ser únicamente texto y se convierte en un objeto.

Por ejemplo:


<h1>Hola</h1>

El navegador transforma esa etiqueta en un objeto con propiedades y métodos.

Podemos imaginarlo como si fuera un objeto de Python:


titulo.texto
titulo.color
titulo.tamaño

En JavaScript ocurre exactamente lo mismo.


const titulo = document.querySelector("h1");

Ahora titulo es un objeto sobre el que podemos trabajar.

Podemos leer o modificar sus propiedades:


titulo.textContent = "Hola Luis";

titulo.style.color = "blue";

Incluso podemos eliminarlo completamente:


titulo.remove();

Todo esto es posible porque el navegador convirtió el HTML en una colección de objetos.

¿Por qué "Documento"?

Porque representa todo el documento HTML, es decir, toda la página web.

Cada etiqueta forma parte de un único árbol que representa el documento completo.

HTML vs DOM

Es muy importante entender esta diferencia.

HTML DOM
Es un archivo de texto. Es un árbol de objetos creado por el navegador.
Lo escribe el desarrollador. Lo construye el navegador automáticamente.
Se almacena en un archivo .html. Existe únicamente en memoria mientras la página está abierta.
No cambia por sí solo. JavaScript puede modificarlo en cualquier momento.

El trabajo de JavaScript

Sin JavaScript, la página permanece prácticamente igual que el HTML original.

Pero cuando JavaScript modifica el DOM...


document.querySelector("h1").textContent = "Hola Luis";

El contenido cambia inmediatamente.

Lo interesante es que el archivo HTML nunca cambió.

Lo único que cambió fue el DOM que vive dentro del navegador.

Relación con las herramientas del desarrollador

Cuando presionamos:


F12

y abrimos la pestaña Elements o Inspector, realmente estamos viendo el DOM, no el archivo HTML original.

Por eso podemos expandir y contraer elementos como si fueran ramas de un árbol.

Analogía

Podemos imaginar el HTML como el plano de una casa.


Plano

El navegador toma ese plano y construye la casa.


Plano
      ↓
Casa construida

En esta analogía:

  • El HTML es el plano.
  • El DOM es la casa ya construida.

JavaScript no modifica el plano.

JavaScript trabaja directamente sobre la casa.

Definición

El DOM (Document Object Model) es la representación en forma de árbol que el navegador crea a partir del documento HTML. Cada elemento se convierte en un objeto que JavaScript puede leer, modificar, agregar o eliminar, permitiendo que el contenido de la página cambie dinámicamente sin necesidad de recargarla.

💡 Idea clave

El navegador no manipula el HTML directamente.

Primero construye el DOM, y es sobre ese árbol de objetos donde JavaScript realiza todas sus modificaciones.
