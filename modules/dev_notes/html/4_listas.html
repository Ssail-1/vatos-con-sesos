Listas

HTML permite organizar información mediante listas. Existen dos tipos principales:

Lista desordenada (<ul>)

Se utiliza cuando el orden de los elementos no es importante. Por defecto utiliza viñetas.


        <ul>
            <li>HTML</li>
            <li>CSS</li>
            <li>JavaScript</li>
        </ul>

Lista ordenada (<ol>)

Se utiliza cuando el orden de los elementos sí tiene importancia o existe una jerarquía. Por defecto utiliza números.


        <ol>
            <li>Instalar VS Code</li>
            <li>Crear el proyecto</li>
            <li>Escribir el código</li>
        </ol>

Personalizar las listas

HTML permite modificar el estilo de las listas mediante algunos atributos. Aunque siguen siendo válidos, actualmente es más común realizar estas personalizaciones utilizando CSS.

type

Permite cambiar el tipo de viñeta o numeración de una lista.

Listas desordenadas (<ul>)


    <ul type="disc">      <!-- ● Predeterminado -->
    <ul type="circle">    <!-- ○ Círculo -->
    <ul type="square">    <!-- ■ Cuadrado -->

Listas ordenadas (<ol>)


    <ol type="1">   <!-- 1, 2, 3... (Predeterminado) -->
    <ol type="A">   <!-- A, B, C... -->
    <ol type="a">   <!-- a, b, c... -->
    <ol type="I">   <!-- I, II, III... -->
    <ol type="i">   <!-- i, ii, iii... -->

start

Permite indicar el número con el que comenzará una lista ordenada.


    <ol start="5">
        <li>Paso</li>
        <li>Paso</li>
    </ol>

reversed

Invierte el orden de la numeración.


    <ol reversed>
        <li>Tres</li>
        <li>Dos</li>
        <li>Uno</li>
    </ol>
💡 Nota: Aunque los atributos type, start y reversed siguen siendo válidos en HTML, actualmente es una mejor práctica personalizar la apariencia de las listas utilizando CSS.
