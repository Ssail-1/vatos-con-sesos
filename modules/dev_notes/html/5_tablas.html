Tablas

Las tablas en HTML se utilizan para representar información organizada en filas y columnas. Son útiles cuando los datos tienen una relación tabular, como horarios, precios, registros o comparaciones.

Etiquetas principales

  • <table>: Contiene toda la tabla.
  • <thead>: Agrupa el encabezado de la tabla.
  • <tbody>: Agrupa el contenido principal de la tabla.
  • <tfoot>: Agrupa el pie de la tabla, normalmente usado para totales o resultados.
  • <tr>: Representa una fila. Viene de table row.
  • <th>: Representa una celda de encabezado.
  • <td>: Representa una celda de datos.
  • colspan: Permite que una celda ocupe varias columnas.

Estructura básica


<table>
    <thead>
        <tr>
            <th>Producto</th>
            <th>Precio</th>
            <th>Cantidad</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>Teclado</td>
            <td>$500</td>
            <td>1</td>
        </tr>

        <tr>
            <td>Mouse</td>
            <td>$300</td>
            <td>2</td>
        </tr>
    </tbody>

    <tfoot>
        <tr>
            <th>Total</th>
            <td colspan="2">$1100</td>
        </tr>
    </tfoot>
</table>

Ejemplo visual

Producto Precio Cantidad
Teclado $500 1
Mouse $300 2
Total $1100

colspan

El atributo colspan indica cuántas columnas debe ocupar una celda. En el ejemplo anterior, la celda del total usa colspan="2", por eso ocupa el espacio de las columnas Precio y Cantidad. 


<td colspan="2">$1100</td>

Alineación de contenido

Históricamente HTML permitía alinear el contenido mediante atributos como align y valign. Actualmente esta tarea se realiza con CSS.

align


        <th align="left">
        
        <th align="center">
        
        <th align="right">

valign


        <td valign="top">
        
        <td valign="middle">
        
        <td valign="bottom">
💡 Nota: Actualmente se recomienda utilizar CSS para controlar la alineación del contenido de una tabla.
