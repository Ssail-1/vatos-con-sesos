<div> y <span>

Son contenedores genéricos que no aportan significado semántico al documento. Se utilizan principalmente para organizar contenido y aplicar estilos con CSS o manipular elementos con JavaScript.

<div>

Es un contenedor de bloque. Se utiliza para agrupar varios elementos cuando no existe una etiqueta semántica más adecuada.


<div class="tarjeta">

    <h2>Curso HTML</h2>

    <p>Aprende HTML desde cero.</p>

</div>
💡 Idea para recordarlo: Un <div> es una caja vacía. Por sí solo no significa nada; adquiere personalidad mediante clases, estilos o JavaScript.

<span>

Es un contenedor en línea. Se utiliza para seleccionar o modificar una parte específica de un texto sin alterar la estructura del documento.


<p>

HTML es un lenguaje

<span class="importante">

muy importante

</span>

para el desarrollo web.

</p>
💡 Idea para recordarlo: Si <div> es una caja para bloques, <span> es un resaltador para pequeñas partes del texto.

¿Cuándo usar <div> y cuándo una etiqueta semántica?

  • Utiliza una etiqueta semántica cuando el contenido tenga un significado claro (<main>, <section>, <article>, etc.).
  • Utiliza <div> cuando solo necesites agrupar elementos sin aportar significado.
Ejemplo: Si un contenido puede describirse con una etiqueta semántica, úsala. Si no existe una etiqueta adecuada, utiliza un <div>.
