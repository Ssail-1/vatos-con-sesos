Diseño de Texto

Color

Se define con:

  • Con nombre
    • color: red;
    • color: green;
    • color: color_name;
  • RGB
    • color: rgb(red(0-255), green(0-255), blue(0-255));
  • Hexadecimal
    • Intensidad: de 00 a FF
    • Primeras 2 cifras: Rojo
    • Siguientes 2 cifras: Verde
    • Siguientes: Azul
    • Ultimos: Alfa (Opacidad o transparencia)
    • color: #_ _ _ _ _ _ _ _
  • HSL (Hue, Saturation, lightness, alpha)
    • color: grados, porcentaje, porcentaje, porcentaje

Alineación de texto

El valor puede ser:

  • center

    • Ejemplo: texto centrado

  • right
  • left
  • justify
text-align: valor;

Tambien se puede alinear el ultimo parrafo.


    p.name_class{
        text-align-last: valor;
    }

Tipografia

font-family: Tipografia;

Tamaño

font-size: #px; donde # es un numero

Texto en negrita

El valor puede ser:

  • normal (400)
  • bold (700)
  • bolder
  • lighter
  • 100 - 900
font-weight: valor;

Inclinación de Texto

Los valores pueden ser:

  • italic -> (varia entre 8° y 16°)
  • oblique -> (14°)
  • Angulo personalizado:
    • oblique #deg
font-style: valor;

Subrayado y tachado

Los valores son:

  • underline
  • line-throught
  • overline
  • text-decoration: underline overline line-through;

    • Se pueden los tres anteriores al mismo tiempo.

  • red solid line-trought
  • green dotted underline
  • blue dashed overline underline

text-decoration: valor;

Interlineado

Distancia de interlineado

line-height: 3

Espaciado de letras

Distancia entre letras

letter-spacing: 4px;

Transformaciones

Podemos modificar el texto. Ponerlo en mayusculas, minusculas y cada palabra con la primera en mayuscula.

text-transform: valor;

Valores:

  • uppercase
  • lowercase
  • capitalize

Existen mas propiedades pero hay que confiar en que encontraremos lo que necesitemos...
