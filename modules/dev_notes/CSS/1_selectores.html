Selectores

Selector por elemento

Selecciona todas las etiquetas del mismo tipo. Los cambios se aplican a todos los elementos que coincidan con ese selector.


/* CSS */

p{
    color: royalblue;
}


<p>Primer párrafo</p>
<p>Segundo párrafo</p>
<p>Tercer párrafo</p>

Resultado

Primer párrafo

Segundo párrafo

Tercer párrafo

Selector por ID

Selecciona un único elemento mediante su atributo id. Para seleccionarlo en CSS se utiliza el símbolo #.


/* CSS */

#titulo{
    color: crimson;
}


<h3 id="titulo">
Dev Notes
</h3>

Resultado

Dev Notes

💡 Idea para recordarlo: Un id es como una CURP: debe ser único dentro del documento.

Selector por clase

Selecciona todos los elementos que contienen una misma clase.

  • Se selecciona utilizando un punto (.) seguido del nombre de la clase.

/* CSS */

.importante{
    color: darkgreen;
    font-weight:bold;
}


<p class="importante">

Este texto es importante.

</p>

Resultado

Este texto es importante.

Más de una clase

Un elemento puede tener varias clases separadas por espacios.


<p class="importante centrado">

Hola <span class="palabras_clave">Dev Notes</span>

</p>


.importante{
    color:darkgreen;
}

.palabras_clave{
    color:red;
}

.centrado{
    text-align:center;
}

Resultado

Hola Dev Notes

Resumen

Selector Símbolo Selecciona
Elemento No utiliza símbolo Todas las etiquetas del mismo tipo.
ID # Un único elemento.
Clase . Todos los elementos que compartan esa clase.
